# 講義資料の構成案

状態: 内容設計。[本編15枚の原稿](lecture-slides.md)と[補足・ヒント・解答の原稿](lecture-appendix.md)を作成済み。Googleスライドへの転記と表示システムは未実装。

対象はプログラミング経験があり、Verilogは初めての人。本編は60分の講義とハンズオンの進行を支え、補足は講義後に一人で読み直し、実験し、次の学習へ進むために使う。

## 学習の到達点

1. CPUの計算・保存・制御を、TD4の回路図で指し示せる。
2. 入力の変化による計算と、クロックによる状態更新を区別できる。
3. 自分が書いたVerilogの部品と、命令実行時の状態変化を対応づけられる。

「Verilogで回路を作る」と「ROMの命令でその回路を動かす」の関係を本編の導入と完成時に説明する。

| --- | --- | --- | --- |

## 補足ページの共通構成

1. どんな疑問に答えるか、前提となる知識。
2. 短い説明と図、または小さなコード例。
3. 実行する前に考える確認問題。
4. 試す手順と期待される結果。
5. 理由を含む解説、間違えやすい点。
6. 対応するハンズオンへのリンク、次に読む補足。

例としてA06では、2個のレジスタが値を受け渡すコードを示し、クロックごとの値を表に埋めてもらう。解説に更新前の値と更新後の値を併記する。初学者向けの書き方の指針と、言語仕様上の一般論を混同しないようにする。

動くWeb上では確認問題の解説を開閉できる形を候補とする。PDFでは問題と解説を別ページに置くなど、紙面だけでも学習できる順番にする。重要な説明や答えを外部リンクやアニメーションだけに依存させない。

## ヒントの設計

本編の3課題、補足の確認問題、追加課題にヒントを付ける。A14は課題ごとにページを分け、必要ならページを増やして、ヒントと解答が同時に目に入らない配置にする。

ヒントは正解へ向けた次の小さな行動を示す。エラー文の言い換えだけで終わらせず、どの入力や信号を見ればよいか、何を予想してから実行すればよいかを伝える。

| 段階 | 役割 | 内容 |
| --- | --- | --- |
| ヒント1 | 考え方を整理する | 入力と出力、値が変わる条件を言葉や図で確認する |
| ヒント2 | 必要な知識を思い出す | 注目する信号、使う構文、関連する補足を示す |
| ヒント3 | 実装を始められる形にする | 空欄付きのコードの骨組みや、実装する処理の順序を示す |
| 解答・解説 | 完成例と理由を理解する | 完成コード、各行の役割、確認例、よくある誤答を示す |

短い確認問題では不要な段階を省略する。ヒントを読んだかどうかは合否や進捗の評価に使わず、必要な段階を受講者が自由に選べるようにする。

### 本編3課題のヒント案

| 課題 | ヒント1 | ヒント2 | ヒント3 |
| --- | --- | --- | --- |
| 加算器 | 15+1を2進数で書くと、何桁必要か考えてみよう | 結果の下位4ビットと、桁上がりの1ビットを分けて扱う。連結の書き方はA04、幅の説明はA08へ | 入力を5ビットに広げて足す式と、結果を切り出す部分を空欄付きで示す |
| レジスタ | クロックが来ても、保存してはいけないのはどんなときだろう | 雛形のリセット処理を確認し、書き込み許可の条件内で`<=`を使う。タイミングはA07へ | クロックとリセット処理の中に、書き込み許可の`if`と代入の空欄を示す |
| PC | 普通の命令の次と、ジャンプ命令の次では、どの番地へ進むだろう | 提供されるジャンプ許可信号に応じて、ロードする番地とPC+1を選ぶ | リセット後の処理として、ジャンプ許可あり・なしの2分岐を空欄付きで示す |

上記は教材文案。信号名とコードの骨組みは、最終的な課題モジュールの入出力契約に合わせて確定する。

### 掲載方法

ハンズオンでは課題の近くにヒント1〜3と解答への入口を置く。初期状態は閉じ、選んだ内容をその場で表示する。失敗した確認例に応じて関連ヒントへのリンクを示しても、本文や解答は自動で開かない。

補足資料には同じヒントを掲載する。PDFでは「課題→ヒント1→ヒント2→ヒント3→解答・解説」の順に配置し、課題ページからヒントのページ番号を参照できるようにする。本編スライドにはヒントの参照先を置き、講師ノートにも誘導のタイミングを記載する。

ヒント・解答・解説は課題IDにひもづけた共通の原稿で管理する。補足とハンズオンで別々の説明を手作業で維持しない構成を目指す。

## 独学向けの読み方

| 目的 | おすすめの順序 |
| --- | --- |
| 講義をもう一度理解したい | A01 → A03 → A04 → A07 → 3課題を再実装 → A14で確認 |
| Verilogの書き方を理解したい | A04 → A05 → A06 → A08 → A12 → A13 |
| CPUの動きを理解したい | A09 → A10 → A11 → A15のROM課題 |
| 回路設計を続けたい | A02 → A12 → A15の回路課題 → A16 |

補足目次はこの目的別の導線と、全テーマ一覧の両方を用意する。A14はヒントと解答に個別の参照先を持たせ、解答へ移るリンクには解答であることを明示する。

## 参考資料の用意

A16には単なるリンク集ではなく、「何を学ぶための資料か」「先に理解しておくこと」「最初に取り組む小さな課題」を添える。

原著『CPUの創りかた』、使用するVerilog処理系の公式資料、HDLの学習資料、FPGAへの導入を候補とする。具体的なリンク、版、対応環境、コマンドは補足本文を作成する時点で確認する。原著の図版をそのまま転載する前提にはせず、教材の図は自作する。

ローカル実行を案内する場合は、インストールから最小のテストベンチ実行までを一続きで説明する。OSごとの差、検証したツールのバージョン、講義Webとの対応も記載する。
